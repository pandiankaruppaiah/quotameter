### Security and Privacy (PII) Review

#### Findings

1. **High: Store directory and files created with default world-readable permissions**
   - **File and line**: [store.js:26](../../plugins/quotameter/lib/store.js#L26), [quotameter.js:105-109](../../plugins/quotameter/bin/quotameter.js#L105-L109), [config.js:24](../../plugins/quotameter/lib/config.js#L24)
   - **Issue**: `fs.mkdirSync(dir, { recursive: true })` and `fs.writeFileSync` / `fs.appendFileSync` create `~/.quotameter` and files using default umask (typically 0755 / 0644). On multi-user Linux and macOS systems, any local user can read `messages.jsonl`, `sessions.jsonl`, `summary.json`, and `report.html`, exposing project paths, git branches, session titles, and full usage metrics.
   - **Fix**: Create `~/.quotameter` with mode `0o700` (`fs.mkdirSync(dir, { recursive: true, mode: 0o700 })` or `fs.chmodSync(dir, 0o700)`). Specify `{ mode: 0o600 }` on all file writes.

2. **High: Session titles (`aiTitle` and `customTitle`) stored and unredacted by `redactPaths`**
   - **File and line**: [logs.js:200-204](../../plugins/quotameter/lib/ingest/logs.js#L200-L204), [analyze.js:366](../../plugins/quotameter/lib/model/analyze.js#L366), [PRIVACY.md:7, 14](../../PRIVACY.md#L7)
   - **Issue**: Claude Code automatically derives `aiTitle` from the user's initial prompt text. While quotameter discards message bodies, `scanFile` extracts and persists `aiTitle` and `customTitle` into `sessions.jsonl`. When `redactPaths` is true, paths and branches are sanitized, but session titles remain unredacted. Furthermore, [PRIVACY.md](../../PRIVACY.md) omits session titles under "What it reads" and claims non-matching fields are discarded.
   - **Fix**: When `redactPaths` is true, omit or hash `customTitle` and `aiTitle` (e.g. use truncated session ID). Update [PRIVACY.md](../../PRIVACY.md) to explicitly state that session titles generated by Claude Code are collected.

3. **Medium: Haiku summary agent receives session titles and branch names**
   - **File and line**: [report/SKILL.md:18-21](../../plugins/quotameter/skills/report/SKILL.md#L18-L21), [usage-analyst.md:8-13](../../plugins/quotameter/agents/usage-analyst.md#L8-L13), [analyze.js:359-366](../../plugins/quotameter/lib/model/analyze.js#L359-L366)
   - **Issue**: When `/quotameter:report` runs the Haiku summary agent, `summary.json` is sent to Anthropic's API. It contains top session titles (which summarize prompt text), git branch names, project names, and MCP tool names. Even when `redactPaths` is enabled, session titles are still transmitted.
   - **Fix**: Sanitize or drop session titles and branch names from `summary.json` before passing to Haiku, particularly when `redactPaths` is true. Clarify in [PRIVACY.md](../../PRIVACY.md) that branch names and prompt-derived session titles are sent to the model for AI summaries.

4. **Medium: Arbitrary file overwrite and execution via unvalidated `--out` parameter**
   - **File and line**: [quotameter.js:48-55, 108-112](../../plugins/quotameter/bin/quotameter.js#L48-L55)
   - **Issue**: The `--out <file>` flag accepts arbitrary file paths without directory or extension validation. It writes the HTML report to the target path and immediately invokes `openFile()`, which launches it via `explorer.exe` (Windows), `open` (macOS), or `xdg-open` (Linux).
   - **Fix**: Validate that `out` resolves within an allowed directory (such as `quotameterHome()`) or strictly ends with `.html`.

5. **Low: Shell command execution in statusline `--wrap`**
   - **File and line**: [statusline.js:54](../../plugins/quotameter/lib/statusline.js#L54), [setup/SKILL.md:21](../../plugins/quotameter/skills/setup/SKILL.md#L21)
   - **Issue**: `runWrapped` spawns wrapped statusline commands using `{ shell: true }`. If an existing command contains complex quotes, wrapping it inside `--wrap "<cmd>"` can cause shell escaping errors or unintended command execution.
   - **Fix**: Document that wrapped commands must be carefully escaped in `settings.json`, or avoid shell invocation when a simple binary path and argument list can be executed directly.

6. **Low: Race condition in `tryLease` release callback**
   - **File and line**: [store.js:170-187](../../plugins/quotameter/lib/store.js#L170-L187)
   - **Issue**: If process A holds `poll.lease` longer than `ttlMs`, process B breaks the stale lease and acquires it. When process A eventually finishes, its release callback runs `fs.rmSync(p)` unconditionally, deleting process B's active lease.
   - **Fix**: Store a token or PID inside the lease folder and only remove the directory on release if the token matches.

7. **Low: GitHub Actions workflow missing least-privilege permissions and SHA pinning**
   - **File and line**: [test.yml:1-16](../../.github/workflows/test.yml#L1-L16)
   - **Issue**: [test.yml](../../.github/workflows/test.yml) specifies no `permissions:`, granting default repository permissions to `GITHUB_TOKEN`. Steps reference mutable tags (`@v4`) rather than immutable commit SHAs.
   - **Fix**: Add `permissions: contents: read` to the top of [test.yml](../../.github/workflows/test.yml) and pin actions to full commit SHAs.

8. **Low: Author location disclosed in comments and tests**
   - **File and line**: [usage-poll.js:51-52](../../plugins/quotameter/lib/ingest/usage-poll.js#L51-L52), [quotameter.test.js:110](../../test/quotameter.test.js#L110)
   - **Issue**: Sample output comments and test strings hardcode `Australia/Sydney`, revealing the author's local timezone.
   - **Fix**: Replace `Australia/Sydney` with generic sample timezones (e.g. `UTC`).

#### What Is Fine

- **Supply chain**: Zero third-party runtime or dev dependencies. Uses only Node standard library modules (`node:fs`, `node:path`, `node:child_process`, `node:crypto`, `node:os`).
- **Prompt and response privacy**: Message text, thinking blocks, and tool input arguments are discarded during parsing in [logs.js](../../plugins/quotameter/lib/ingest/logs.js) and never written to disk.
- **Sensitive files and credentials**: Credentials, OAuth tokens, browser storage, and cookies are never opened. Desktop web storage is only inspected for folder modification timestamps.
- **XSS in report.html**: Safe. `<` characters in JSON data are replaced with `\u003c`, Unicode line separators are escaped, dynamic values in HTML tables are escaped via `esc()`, and a strict CSP (`default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; img-src data:`) is enforced.
- **Windows Claude CLI spawning**: Executed safely without invoking arbitrary shell evaluation. Windows `.cmd` fallback uses `cmd.exe /d /s /c` with static argument arrays.
- **Session hooks**: Hooks detach immediately and exit, avoiding session latency. Hook stdin is not read.
- **Cross-process locking**: Directory creation lock in `withLock` is atomic across platforms and safely detects dead PIDs.
- **Author contact privacy**: Author git email in [.git/config](../../.git/config) uses a GitHub noreply address. No private emails, phone numbers, or passwords are exposed.
